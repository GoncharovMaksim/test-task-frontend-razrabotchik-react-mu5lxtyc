# MAX Chat Client (GREEN-API)

Веб-клиент мессенджера MAX для отправки и получения текстовых сообщений с использованием шлюза GREEN-API.

## Live Demo
Деплой проекта доступен по адресу:
[https://test-task-frontend-razrabotchik-rea.vercel.app](https://test-task-frontend-razrabotchik-rea.vercel.app)

---

## Реализованный функционал

1. **Авторизация и настройка инстанса**:
   - Ввод учетных данных `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.
   - Возможность указать кастомный `apiUrl` (по умолчанию `https://api.green-api.com`).
   - Автоматическая проверка состояния инстанса методом `getStateInstance`.
   - Безопасное локальное сохранение в `localStorage` браузера (секреты не передаются на сторонние бэкенды).

2. **Создание чатов**:
   - Создание нового чата по номеру телефона получателя в MAX.
   - Автоматическая валидация (10–15 цифр) и нормализация номеров (форматы РФ `+7` / `8`, СНГ и международные).
   - Приведение к формату `chatId` (`79991234567@c.us`).
   - Быстрый поиск и фильтрация по существующим контактам.

3. **Отправка сообщений**:
   - Метод: `POST {{apiUrl}}/waInstance{{idInstance}}/sendMessage/{{apiTokenInstance}}`
   - Только текстовые сообщения в соответствии с техническим заданием.
   - Оптимистичный UI: мгновенное добавление сообщения со статусом отправки (`sending`).
   - Индикаторы доставки: `sending` (таймер), `sent` (одна галочка), `delivered` (две галочки), `read` (двойная синяя галочка), `failed` (ошибка с возможностью повторной отправки).
   - Поддержка горячих клавиш: `Enter` — отправка, `Shift + Enter` — перенос строки.

4. **Получение входящих сообщений (HTTP API)**:
   - Метод: `GET {{apiUrl}}/waInstance{{idInstance}}/receiveNotification/{{apiTokenInstance}}?receiveTimeout=5`
   - Непрерывный цикл опроса очереди с таймаутом ожидания 5 секунд.
   - Автоматическое распознавание событий `incomingMessageReceived` и извлечение текста.
   - Автоматическое добавление неизвестных номеров в список контактов при получении входящего сообщения.
   - Подтверждение и очистка очереди методом `DELETE {{apiUrl}}/waInstance{{idInstance}}/deleteNotification/{{apiTokenInstance}}/{{receiptId}}`.
   - Экспоненциальный backoff при временных сетевых ошибках.

5. **Интерфейс в стиле web.max.ru**:
   - Строгий минималистичный дизайн (стиль темной/светлой темы Linear / Telegram Web / web.max.ru).
   - Адаптивная верстка (десктопная двухколоночная панель и мобильный режим).
   - Звуковые уведомления при входящих сообщениях (Web Audio API без внешних аудиофайлов).
   - Группировка сообщений по датам («Сегодня», «Вчера», дата).

```

│   │   └── useGreenApiPolling.ts # Хук получения и удаления уведомлений
│   ├── services/
│   │   ├── greenApi.ts     # Клиент API (SendMessage, ReceiveNotification, DeleteNotification)
│   │   └── storage.ts      # Слой работы с localStorage

│   └── utils/              # Форматирование номеров, дат, цвета аватаров

└── vercel.json             # Конфигурация деплоя SPA
```

## Инструкция по локальному запуску

### Вариант 1: Запуск через Node.js / npm

**Требования:** Node.js >= 18, npm >= 9

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/GoncharovMaksim/test-task-frontend-razrabotchik-react-mu5lxtyc.git
   cd test-task-frontend-razrabotchik-react-mu5lxtyc
   ```

2. Установить зависимости:
   ```bash
   npm install
   ```

3. Запустить проект в режиме разработки:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:3000`.

4. Сборка production-бандла:
   ```bash
   npm run build
   ```

5. Запуск тестов:
   ```bash
   npm test
   ```

---

### Вариант 2: Запуск в Docker Compose

**Требования:** Docker и Docker Compose

1. Собрать и запустить контейнер:
   ```bash
   docker compose up -d --build
   ```

2. Открыть в браузере:
   `http://localhost:3000`

3. Остановка контейнера:
   ```bash
   docker compose down
   ```

## Проведение тестирования сценария ТЗ

1. Зайти на сайт (или открыть локально).
2. При первом входе откроется окно настроек GREEN-API:
   - Введите ваш `idInstance` и `apiTokenInstance` из личного кабинета [console.green-api.com](https://console.green-api.com).
   - Нажмите «Подключиться к MAX». Инстанс пройдет автоматическую проверку статуса.
3. Нажмите кнопку «Новый чат в MAX»:
   - Введите номер телефона получателя (например, свой личный номер с установленным мессенджером MAX).
   - Нажмите «Создать чат».
4. В поле ввода наберите текст и нажмите клавишу `Enter` (или иконку отправки).
5. Получатель получит сообщение в мессенджере MAX и отправит ответ.
6. Входящее сообщение отобразится в чате через автоматический HTTP API опрос, и уведомление будет удалено из очереди сервиса.
